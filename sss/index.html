Apri il registro

Trascina qui SR16_P07_SANIFICAZIONI_SALA_SCIROPPI.xlsx oppure premi il pulsante.

Come funziona. L'app legge il foglio sanificazioni e scrive solo i valori delle celle dentro il file originale: stili, colori, formattazione condizionale e gli altri fogli restano intatti. A fine turno premi Scarica file aggiornato e sostituisci l'originale sul server. Il browser non può salvare direttamente sul file di partenza.
