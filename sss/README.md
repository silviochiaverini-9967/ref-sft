# 🍃 Gestionale Magazzino Tè

Applicazione web per la gestione del magazzino tè (limone, pesca, verde) con salvataggio automatico su Excel.

## ✨ Funzionalità
- Griglia visiva: 24 posti parte alta + 36 parte bassa + 2 fuori stoccaggio
- Non conformità riservate su A1, A2, A3
- Lotti con banda laterale + codice in grassetto colorato
- Priorità di consumo con pallini 🔴🔵🟢 calcolati per scadenza
- Scadenze in formato "Mar 2027"
- Contatore posti liberi (rosso sotto 22)
- Drag & drop e click destro per copia/incolla
- Salvataggio Excel automatico (Chrome/Edge/Opera) con fallback per altri browser

## 🚀 Uso
1. Apri `index.html` con **Chrome**, **Edge** o **Opera**
2. Clicca "📂 Apri file Excel" o "🆕 Nuovo file"
